## 💡 什么是 Frostnux？

**Frostnux（霜砧）** 是一名初中生居家自研的一款轻量级开源 IDE，旨在为代码开发提供另一种可能。

它完全基于 **C++** 和 **OpenGL** 从零打造，摒弃了 Electron 等笨重的跨平台框架，为你带来原生的极速体验与极高的可定制性。

- **当前版本：** `2026.4.1`
- **支持语言：** C++ (Modern Standards)

## ✨ 核心特性

- 🚀 **原生性能**：C++ 内核配合 OpenGL 渲染管线，启动迅速、内存占用低。
- 🎨 **自定义主题**：内置主题系统与语法高亮，打造属于你的开发环境。
- 📑 **多标签页**：高效的工作区管理，随时切换上下文。
- 🌍 **多语言界面**：支持中文、英文、俄文等多种语言。

## 💡 What is Frostnux?

**Frostnux (霜砧)** is a lightweight, open-source IDE independently developed at home by a middle school student, aiming to provide another possibility for code development.

Built entirely from scratch with **C++** and **OpenGL**, it avoids heavy frameworks like Electron, ensuring a native, fast, and highly customizable experience.

- **Current Version:** `2026.4.1`
- **Language Support:** C++ (Modern Standards)

## ✨ Features

- 🚀 **Native Performance:** C++ core and OpenGL rendering pipeline.
- 🎨 **Custom Themes:** Built-in theme system and syntax highlighting.
- 📑 **Multi-tab Support:** Efficient workspace management.
- 🌍 **Multi-language UI:** Supports English, Chinese, Russian, etc.

## 🛠️ Build from Source

*(Requirements: C++20 compatible compiler, OpenGL)*

```bash
# Clone the repository
git clone https://github.com/Coding-Penguin/Frostnux.git
cd Frostnux
```

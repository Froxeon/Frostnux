## 💡 什麼是 Frostnux？

**Frostnux（霜砧）** 是一名初中生居家自研的一款輕量級開源 IDE，旨在為程式碼開發提供另一種可能。

它完全基於 **C++** 和 **OpenGL** 從零打造，捨棄了 Electron 等笨重的跨平台框架，為你帶來原生的極速體驗與極高的可自訂性。

- **當前版本：** `2026.4.1`
- **支援語言：** C++ (Modern Standards)

## ✨ 核心特性

- 🚀 **原生效能**：C++ 核心配合 OpenGL 渲染管線，啟動迅速、記憶體佔用低。
- 🎨 **自訂主題**：內建主題系統與語法突顯，打造屬於你的開發環境。
- 📑 **多分頁支援**：高效的工作區管理，隨時切換上下文。
- 🌍 **多語言介面**：支援中文、英文、俄文等多種語言。
